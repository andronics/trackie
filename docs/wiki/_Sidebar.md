### 🔑 Key Features

- 🌐 Reads the tracker's own Peers and Hit & Run pages
- 🔗 Tracker ID → qBittorrent hash matching, persisted
- 🛡️ Fails safe: never serves a guess as "satisfied"
- 🐳 One container: Docker Compose or Kubernetes
