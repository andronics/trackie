### ⚠ BREAKING CHANGES

* a config file is now /etc/trackie/config.yaml (TRACKIE_CONFIG) with flat keys (trackers.<site>.* is <site>.*, sources.<app>.* is <app>.*, http.timeout is timeout); an old /config/config.yml or old keys stop startup with what to change. TRACKIE_MAX_BACKOFF is TRACKIE_POLL_MAX_BACKOFF. Python 3.13 or later. Environment-only deployments need nothing: /config/state is still used.
